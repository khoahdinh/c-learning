# Problem-Solving Workflow / Quy trình giải bài toán

## English Version

### Steps to solve a programming problem:

1. **Read the problem carefully**
   - Understand what the problem is asking
   - Identify key requirements and constraints

2. **Define Input - Output**
   - Clearly specify what data goes in
   - Clearly specify what result comes out

3. **Use concrete real-world examples**
   - Visualize with familiar scenarios (e.g., cards, books, emails)
   - Make the problem tangible and easier to understand

4. **Identify the PATTERN from examples**
   - Manually solve the example step-by-step
   - Observe recurring behaviors or rules
   - Extract the algorithm logic

5. **Code based on the pattern**
   - Translate the pattern into code
   - Keep the implementation simple and clear

6. **Test with initial examples**
   - Verify the code works with your examples
   - Test edge cases (empty arrays, single elements, etc.)

## Phiên bản Tiếng Việt

### Các bước giải bài toán lập trình:

1. **Đọc kỹ đề bài**
   - Hiểu rõ bài toán yêu cầu gì
   - Xác định các yêu cầu và ràng buộc chính

2. **Xác định Input - Output**
   - Xác định rõ dữ liệu đầu vào
   - Xác định rõ kết quả đầu ra

3. **Lấy ví dụ thực tế cụ thể**
   - Hình dung bằng các tình huống quen thuộc (ví dụ: bài, sách, email)
   - Làm cho bài toán dễ hình dung và dễ hiểu hơn

4. **Từ ví dụ → Nhìn ra PATTERN**
   - Tự giải ví dụ từng bước bằng tay
   - Quan sát các quy luật hoặc hành vi lặp lại
   - Rút ra logic thuật toán

5. **Code theo pattern**
   - Chuyển pattern thành code
   - Giữ code đơn giản và rõ ràng

6. **Test với ví dụ ban đầu**
   - Kiểm tra code hoạt động đúng với ví dụ
   - Test các trường hợp đặc biệt (mảng rỗng, 1 phần tử, v.v.)

## Example / Ví dụ

**Problem:** Merge two sorted arrays into one sorted array.

**Bài toán:** Trộn hai mảng đã sắp xếp thành một mảng sắp xếp.

```
Input:  a[] = {1, 3, 5}, b[] = {2, 4, 6}
Output: c[] = {1, 2, 3, 4, 5, 6}

Real-world analogy: Merging two sorted decks of cards
Ví dụ thực tế: Trộn hai chồng bài đã sắp sẵn

Pattern: Compare top cards, take the smaller one, move pointer
Pattern: So sánh hai lá bài trên cùng, lấy lá nhỏ hơn, dịch con trỏ
```
